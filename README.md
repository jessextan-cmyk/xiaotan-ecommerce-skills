# 小谈的电商 Skill

面向电商卖家和运营的开源 AI 技能导航。当前目录整理了 161 条技能索引，可按平台、任务和能力搜索，并查看来源、费用说明、依赖和安装指引。

## 下载与安装

1. 打开 [Skill 安装包](./xiaotan-ecommerce-skills.zip)，点击 GitHub 的下载按钮。
2. 解压后保留整个 `xiaotan-ecommerce-skills` 文件夹。使用 Codex 时，将它复制到项目的 `.agents/skills/` 下，再开启新的对话。其他支持本地 Skill 的客户端可按各自的导入方式操作。
3. 在对话中输入：使用 `$xiaotan-ecommerce-skills`，帮我找适合 TikTok Shop 选品的技能，列出费用、依赖和安装方法。

本地检索需要 Node.js 22+。只想浏览目录，可以用电脑浏览器打开安装包内的 `assets/ecommerce-skills.html`。

目录中的外部 Skill 可按各自的来源安装，部分需要额外账号或付费服务。目录条目尚未逐个验证业务效果。
